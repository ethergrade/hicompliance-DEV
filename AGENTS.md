
- Asset Management (registro per cliente, tabelle managed_assets*) è separato da Inventario Asset (consistenze numeriche); HaloPSA sincronizza solo in lettura via funzione server halo-asset-sync, perché le credenziali Halo non devono mai arrivare al browser.
- Module visibility per client is decided only by src/config/moduleServiceMap.ts + useModuleAccess (route → active tenant_services.service_type), so sidebar, guard and dashboard never diverge.
- Asset Management register column geometry is defined by ASSET_TABLE_COLUMNS and ResizableAssetHeader with a fixed-layout colgroup, so headers, filters and body cells remain aligned during pointer resizing.
- Nove VA requests use server-only NOVE_API_BASE_URL with legacy NOVE_API_HOST fallback and normalize the API root once, preventing duplicated version paths.
- Assessment import/external scores are additive only: imported answers enter assessment_responses with source='import' and external scores live in assessment_external_scores shown side-by-side, because scoring.ts, snapshots and Gap Analysis must keep reading the same tables unchanged.
- Document versioning: incident_documents stays the current version and document_versions holds every downloadable revision; revision advances only via documentsApi.createRevision and status moves only via setStatus transitions (Bozza → In Revisione → Approvato → Obsoleto), so ISO history is never lost.
- NIS2 ACN path (classification wizard, ACN catalog, nis2_acn_responses) is additive and separate from the proprietary assessment; the catalog JSON in src/data/nis2Acn is the single source of measures/requirements and legacy correlation is a keyword proposal that only suggests answers, so existing scoring, snapshots and reports never change.
- Badge forwards its DOM ref so Radix tooltip triggers anchor to the visible badge instead of positioning outside the viewport; the NIS2 sidebar entry inherits Assessment visibility and permissions.
- Client anagrafica is stored atomically in organization_profiles through the authenticated Supabase client and existing RLS; merge profiles into tenant reads and translate the stored NIS2 enum at the UI boundary to prevent legacy API authentication failures and divergent classifications.
- Document review reminders: incident_documents.review_due_date drives DocumentReviewBoard (dashboard + Gestione Documentale) and the document-review-reminders edge function (Resend; immediate mail on date set, sweep for ≤7 days triggered on page open), so UI and emails share one date.
